lunch-notification

lunch-notification is a personal, self-hosted tool. Once a day it reads tomorrow's meal plan from the owner's own Google Sheet and adds one Google Tasks entry per meal, so the owner knows what to prepare.

It runs on the owner's private server, is not offered as a service, and is not intended for use by anyone other than its owner.

Google data used

  • Google Sheets, read-only (spreadsheets.readonly): reads the meal plan sheet.
  • Google Tasks (tasks): lists tomorrow's tasks to avoid duplicates and creates the meal tasks.
