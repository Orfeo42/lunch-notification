Privacy policy

Last updated: 2026-10-11

Who is responsible

lunch-notification is a personal tool operated by its owner for their own Google account only. Contact: lucio.rosadini87@gmail.com.

What data is accessed

  • Google Sheets (read-only): the contents of the meal plan spreadsheet configured by the owner.
  • Google Tasks: titles and due dates of tasks in the configured task list, to avoid creating duplicates, and creation of new meal tasks.

How data is used

Data is used only to create the owner's daily meal tasks. It is not used for advertising, analytics, profiling or training of any model, and it is not sold or shared with any third party.

Storage

Spreadsheet and task contents are processed in memory and not stored. The only persisted data is the OAuth token, kept on the owner's private server with restricted file permissions so the tool can act on the owner's behalf. Application logs on that server may contain task titles.

Limited Use

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections, which immediately invalidates the stored token.
